ANDYKIT — OpenFX plugin for DaVinci Resolve Studio
====================================================

1. Close DaVinci Resolve.

2. Copy the folder "AndyKit.ofx.bundle" here:

   macOS    /Library/OFX/Plugins/
   Windows  C:\Program Files\Common Files\OFX\Plugins\
   Linux    /usr/OFX/Plugins/

   (create the folders if they do not exist; you need admin rights)

3. macOS only — the plugin is not notarized, so remove the download quarantine
   once, in Terminal:

   sudo xattr -dr com.apple.quarantine /Library/OFX/Plugins/AndyKit.ofx.bundle

4. Open Resolve. In the Effects library: OpenFX > Filters > ANDYTHEFILMMAKER > AndyKit.
   Drag it onto a clip (Edit page) or a node (Color page).

5. Pick a look in "Presets > Preset" and press "Apply Preset".
   The built-in looks are demos. Save your own with "Save Preset to File":
   files go to Documents/AndyKit Presets/ (or any path you type) and show up
   in the Preset menu the next time Resolve starts.

Tip: Pixel Memory replays the previous frames (Memory Warm-up Frames) so every frame
renders the same whether you play, scrub or render. Lower the warm-up for faster scrubbing.

ITALIANO

1. Chiudi DaVinci Resolve.
2. Copia la cartella "AndyKit.ofx.bundle" in:
   macOS    /Library/OFX/Plugins/
   Windows  C:\Program Files\Common Files\OFX\Plugins\
   Linux    /usr/OFX/Plugins/
3. Solo macOS, una volta sola, nel Terminale:
   sudo xattr -dr com.apple.quarantine /Library/OFX/Plugins/AndyKit.ofx.bundle
4. Apri Resolve: Effects > OpenFX > Filters > ANDYTHEFILMMAKER > AndyKit.
5. Scegli un look in "Presets > Preset" e premi "Apply Preset".
   I look inclusi sono demo. Salva i tuoi con "Save Preset to File": finiscono in
   Documenti/AndyKit Presets/ (o nel percorso che scrivi) e compaiono nel menu
   Preset al successivo avvio di Resolve.
